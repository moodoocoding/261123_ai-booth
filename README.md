# AI 체험 부스 모음 페이지 (청주소로초 디지털 마스터)

2026 충북 AI 페스티벌 체험 부스의 첫 화면입니다. 학생들이 만든 AI 웹앱과 게임 16개를 한곳에 모아, 카드를 누르면 바로 시작됩니다.

- **실제 첫 화면 프리뷰 (`thumbs/`)**: 16개 웹앱·게임의 실제 첫 화면 썸네일과 한 줄 **'이렇게 체험해 보세요'** 안내를 함께 보여 줍니다.
- **탭 필터**: `전체(16)`, `🏆 랭킹 도전 게임(12)`, `✨ 자유 체험 앱(4)`(`?tab=free`), `👫 친구와 함께(5)` 및 과목·분류별로 골라 볼 수 있습니다.
- **QR 코드**: 상단 `📱 전체 QR 코드` 또는 각 카드의 `QR` 버튼을 누르면 스마트폰·태블릿용 QR 코드가 나옵니다.
- **실시간 랭킹 연동**: `board.js`를 통해 오늘 부스 총 도전 횟수와 각 랭킹 게임의 현재 1위 기록을 카드 하단에 실시간으로 표시합니다.
