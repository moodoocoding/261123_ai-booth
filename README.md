# AI 체험 부스 모음 페이지

2026 충북 AI 페스티벌 체험 부스의 첫 화면입니다. 학생들이 만든 게임 13개를 한곳에 모아, 카드를 누르면 바로 시작됩니다.

- 과목(국어·수학·과학·사회·퀴즈·두뇌·액션)과 "여럿이 함께"로 골라 볼 수 있습니다.
- "내 휴대전화로 하기 (QR)"를 누르면 카드마다 QR 코드가 나옵니다.
- 오늘의 랭킹(TV 화면)으로 가는 버튼이 있습니다.
- 게임을 더하려면 `index.html`의 `GAMES` 목록에 한 줄을 추가합니다.
